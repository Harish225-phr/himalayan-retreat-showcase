# Negi Cottage Premium Website

## Build
- Replace the placeholder homepage with a cinematic, responsive Negi Cottage site using the nine supplied property photos as direct React imports.
- Create a transparent overlay navigation, full-screen mountain hero, introduction, highlights, spacious room presentation, editorial experience and dining sections, masonry gallery with fullscreen lightbox, location map, and booking/contact area.
- Route every booking, enquiry, and contact action to WhatsApp with the supplied pre-filled message; add call, directions, and floating WhatsApp actions.

## Visual direction
- Use a refined Himalayan palette of forest green, warm cream, charcoal, and restrained gold.
- Pair elegant display typography with clean body text, expansive photography, subtle glass treatments, restrained parallax, and scroll-triggered reveals.
- Avoid repetitive card grids; use asymmetric editorial compositions and image-led storytelling across desktop and mobile.

## SEO and quality
- Add route-specific title, description, Open Graph and Twitter metadata, canonical URL, semantic headings, descriptive image alt text, and Hotel/LocalBusiness structured data.
- Preserve and update crawler access; defer a new sitemap until a public site URL exists, as required for correct canonical sitemap entries.
- Verify the live preview on desktop and mobile, including navigation, gallery lightbox, WhatsApp links, map, and layout stability.

## Technical details
- Copy the uploaded PNG files into `src/assets/` and import them directly in React; no JSON image manifests, base64, external images, placeholders, stock, or generated imagery.
- Keep all colors, shadows, motion, and typography in the shared Tailwind v4 design system.
- Use the exact Google Maps iframe supplied by the user.
